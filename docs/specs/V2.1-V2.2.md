# V2.1 visual system and V2.2 product corrections

The released baseline is `v1.0.0` (`50dccfc`). This document records the approved V2.2 corrections and takes precedence over conflicting V1 and initial V2 specifications. Madrid week boundaries, immutable historical snapshots, shopping operations and recipe draft/publication rules still apply.

| Requirement | Product contract |
|---|---|
| INT-01 | A missing editable week opens with all 14 slots. Reads and filters leave storage untouched. The first valid edit creates the week and commits the edit atomically. The explicit creation route has been removed. |
| INT-02, INT-07 | The single mutable template supplies a live category and icon in subdued text before opening any empty editable slot. `Tria un plat` remains the action. `Lliure` clears the hint and defaults to all categories. Selected and skipped slots keep their own states. Historical views never use the current template. Existing stored hints are legacy copies, and the domain has no explicit per-slot override. The compatibility policy is read-time only, with no migration or backfill. |
| INT-03, INT-04 | The picker opens with the current suggested category. Every eligible dish remains selectable without a warning. Category controls and debounced, composition-aware search update results immediately. Tap a dish to assign or replace it. Tap a template category to save it. Filtered ranking stays exact. In unfiltered views, dishes are grouped by primary category within each ranking tier, with its first ranked member setting the group order. |
| INT-05 | Shared accessible dialogs confirm archive, removal, skipping an occupied slot, moving into a skipped slot, discarding dish or recipe edits and manual shopping removal. Ordinary moves, exchanges, restoration and reactivation are direct. Native server-rendered fallbacks remain available. |
| INT-06 | A successful write is shown only after commit. Stale versions require review, and a retry cannot silently overwrite a change. Preserve week and slot context, CSRF, atomic undo, and the saved recipe when leaving the editor. |
| ICON-01 | Fourteen local multicolour SVG files cover the thirteen canonical categories and `Lliure`. Category components preserve original fills and strokes. Navigation and action icons remain monochrome. The `salads` key keeps its identity and displays as `Amanides`. |

The browser targets are 360×800 and 390×844 portrait phones, plus 800×480 and 1024×600 landscape tablets. Compact tablet cards show up to four lines of a long dish name. The action sheet, link accessible name and detail provide the full name.

Run `.venv/bin/python scripts/verify-browser.py` with Playwright and Chromium available. The script starts a temporary loopback server with a newly migrated SQLite database and synthetic data. Set `MENU_BROWSER_SCREENSHOTS` to a temporary directory to retain captures. Run the Django suite using a disposable file-backed test database for concurrency coverage. See the [owner QA handoff](../V2.2-OWNER-QA.md) for verified results and the separate real-device review.

# Menú Familiar V2.0.1

The installable app starts at /menu/ and keeps all application routes in the same standalone window. Django serves a Catalan manifest and local PNG icons. Private pages and recipe photos send Cache-Control with private and no-store. No service worker is registered, so an installed app needs a live connection to load menus, recipes or photos. Install through the browser menu on the tailnet HTTPS origin. The LAN HTTP URL remains available for normal browser use. [Chrome installation guidance](https://developer.chrome.com/blog/update-install-criteria).

## Deployment boundary

The existing LAN mapping remains 192.168.1.22:18766 to container port 8000. The new host loopback mapping is 127.0.0.1:18768 to container port 8001. The latter accepts requests only from the configured IPv4 gateway of the project's Docker bridge and with both Host and X-Forwarded-Host equal to homeserver.tail02b38e.ts.net:8443 and X-Forwarded-Proto equal to https. Gunicorn's generic forwarded-header trust is disabled. Django checks the exact HTTPS origin or Referer for CSRF and sends Secure CSRF and session cookies on the proxy path. LAN traffic ignores forwarded headers and retains HTTP cookies and regular CSRF checks. There is no cross-origin CSRF exception. The proxy listener fails closed when unconfigured. [Tailscale Serve reverse proxy implementation](https://github.com/tailscale/tailscale/blob/main/ipn/ipnlocal/serve.go).

Run the following as the repository owner on the Home Server. This procedure assumes the existing rootful Docker Compose bridge with standard NAT, Docker Engine 28 or later, and a tailnet configured for HTTPS certificates and restricted to authorized household clients on TCP 8443. The bridge is already in use by Menú Familiar. Host-local processes with access to the backend and Docker administrators are inside the server trust boundary. If any preflight check fails, leave the HTTPS endpoint disabled. These steps change only the Menú Familiar service and the new Serve listener on 8443. AI Engineering Academy keeps its existing port 18767. Nextcloud and Serve on 443 stay active. [Docker port publishing](https://docs.docker.com/engine/network/port-publishing/) · [Tailscale Serve CLI](https://tailscale.com/docs/reference/tailscale-cli/serve).

## Activate Menú Familiar, then the HTTPS listener

Run the first block in the same shell. It expects the simple .env format produced by the V2.0.0 first-installation procedure and keeps the existing hosts, secret and data directory. A brief LAN interruption is expected while Compose recreates Menú Familiar. This release has no schema changes. The preflight runs migrate --check without applying migrations. If a check fails after replacement, use the rollback instructions before continuing.

~~~bash
env_next=$(mktemp "$repo/.env.v2.0.1.XXXXXXXX")
python3 - "$work/production.env" "$env_next" "$image" "$tailhost" "$gateway" <<'PY'
from pathlib import Path
import re
import sys

source, target, image, host, gateway = sys.argv[1:]
lines = Path(source).read_text().splitlines()
values = {}
for line in lines:
    if not line.strip() or line.lstrip().startswith("#"):
        continue
    match = re.fullmatch(r"([A-Z_][A-Z_0-9]*)=([^\s#]+)", line)
    if not match or match[1] in values:
        raise SystemExit("Expected unique, unquoted V2.0.0 environment assignments")
    values[match[1]] = match[2]
required = {"MENU_BIND_ADDRESS": "192.168.1.22", "MENU_PORT": "18766", "MENU_DATA_DIR": "/var/lib/menu-familiar/data"}
if any(values.get(key) != value for key, value in required.items()):
    raise SystemExit("Production bind or storage differs from the runbook")
hosts = values["DJANGO_ALLOWED_HOSTS"].split(",")
if "192.168.1.22" not in hosts or any(not re.fullmatch(r"[a-zA-Z0-9.\-]+", item) for item in hosts):
    raise SystemExit("Expected explicit LAN hosts")
changes = {
    "DJANGO_ALLOWED_HOSTS": ",".join(dict.fromkeys([*hosts, host])),
    "DJANGO_TAILSCALE_HOST": host,
    "DJANGO_TAILSCALE_PROXY_IP": gateway,
    "MENU_IMAGE": image,
}
Path(target).write_text("\n".join([line for line in lines if line.partition("=")[0] not in changes]
                                  + [f"{key}={value}" for key, value in changes.items()]) + "\n")
PY
sudo docker compose -p menu-familiar --env-file "$env_next" -f "$repo/compose.yaml" config --quiet
sudo docker compose -p menu-familiar --env-file "$env_next" -f "$repo/compose.yaml" \
    run --rm --no-deps --pull never -T menu-familiar python manage.py migrate --check
cmp "$repo/.env" "$work/production.env"
test "$(oldprod ps -q menu-familiar)" = "$old"
test "$(sudo docker image inspect --format '{{.Id}}' "$image")" = "$image_id"
mv -T "$env_next" "$repo/.env"
prod up -d --no-build --pull never menu-familiar
live=$(prod ps -q menu-familiar)
test "$(sudo docker inspect --format '{{.Image}}' "$live")" = "$image_id"
test "$(sudo docker port "$live" 8000/tcp)" = 192.168.1.22:18766
test "$(sudo docker port "$live" 8001/tcp)" = 127.0.0.1:18768
test "$(curl --noproxy '*' -fsS --retry 8 --retry-connrefused --retry-delay 1 --max-time 5 "$lan/healthz")" = OK
test "$(curl --noproxy '*' -sS --max-time 5 -o /dev/null -w '%{http_code}' http://127.0.0.1:18768/healthz)" = 403
test "$(curl --noproxy '*' -fsS --max-time 5 \
    -H "Host: $authority" -H "X-Forwarded-Host: $authority" -H 'X-Forwarded-Proto: https' \
    http://127.0.0.1:18768/healthz)" = OK
curl --noproxy '*' -fsSL --max-time 5 -o /dev/null "$lan/menu/"
~~~

If the simulated proxy request returns 403, the backend has rejected the actual peer address or headers. Stop here and use rollback. Keep the exact-IP trust boundary.

The next command adds only the preflighted 8443 HTTPS listener. Confirm that Serve reports tailnet access and the existing 443 entry remains the same.

~~~bash
sudo tailscale serve --bg --https=8443 http://127.0.0.1:18768
sudo tailscale serve status --json > "$work/serve-after.json"
sudo tailscale serve status
python3 - "$work/serve-before.json" "$work/serve-after.json" "$authority" <<'PY'
import json
import sys
from pathlib import Path
before, after = [json.loads(Path(path).read_text()) for path in sys.argv[1:3]]
authority = sys.argv[3]
assert after["TCP"].pop("8443")["HTTPS"]
assert after["Web"].pop(authority)["Handlers"]["/"]["Proxy"] == "http://127.0.0.1:18768"
assert before == after, "A pre-existing Serve entry changed"
PY
test "$(curl --noproxy '*' -fsS --max-time 15 "$https/healthz")" = OK
for path in /menu/ /plantilla/ /plats/ /compra/; do
    curl --noproxy '*' -fsSL --max-time 10 -o /dev/null "$https$path"
done
curl --noproxy '*' -fsS --max-time 10 -D "$work/manifest.headers" "$https/manifest.webmanifest" > "$work/manifest.json"
grep -qi '^Content-Type: application/manifest+json' "$work/manifest.headers"
python3 - "$https" "$work/manifest.json" <<'PY'
import json
from pathlib import Path
from struct import unpack
import sys
from urllib.request import ProxyHandler, build_opener

origin, path = sys.argv[1:]
manifest = json.loads(Path(path).read_text())
assert (manifest["start_url"], manifest["scope"], manifest["display"]) == ("/menu/", "/", "standalone")
assert {icon["sizes"] for icon in manifest["icons"]} == {"192x192", "512x512"}
opener = build_opener(ProxyHandler({}))
for icon in manifest["icons"]:
    assert icon["src"].startswith("/static/menus/pwa/")
    with opener.open(origin + icon["src"], timeout=10) as response:
        assert response.headers.get_content_type() == "image/png"
        header = response.read(24)
        assert header.startswith(b"\x89PNG\r\n\x1a\n")
        assert "x".join(map(str, unpack(">II", header[16:24]))) == icon["sizes"]
PY
~~~

On a trusted tailnet device, open the HTTPS menu, inspect a saved week, open a recipe photo, and check the browser's installation option and standalone navigation. Test a normal authorized form submission there. Open the LAN URL from a trusted LAN device and confirm that the loopback backend is unreachable at 192.168.1.22:18768. Test 8443 from an unauthorized tailnet client and from outside the tailnet, and confirm that neither can reach it. Confirm Nextcloud still opens on its original HTTPS URL. Keep the existing tailnet access rules in force. If 8443 is exposed beyond the intended clients, remove the 8443 mapping immediately.

## Rollback

If the 8443 mapping was enabled by this deployment, remove only that mapping. Skip the first command if it was never added. Keep the existing Serve configuration on 443.

~~~bash
sudo tailscale serve --bg --https=8443 http://127.0.0.1:18768 off
sudo tailscale serve status
~~~

Restore the previous image and configuration with the saved Compose file. Leave the persistent data in place so edits made since the update survive. Use the backup for data recovery only if the data itself needs restoration, following the V2.0.0 recovery procedure.

~~~bash
(
set -euo pipefail
umask 077
cd /home/natalio/homeserver/menu-familiar
unset DOCKER_HOST DOCKER_CONTEXT COMPOSE_ENV_FILES COMPOSE_PROFILES

    sudo docker image load --input "$work/image-v2.0.0.tar"

    up -d --no-build --pull never menu-familiar
test "$(curl --noproxy '*' -fsS --retry 8 --retry-connrefused --retry-delay 1 --max-time 5 http://192.168.1.22:18766/healthz)" = OK
~~~

After rollback, use the saved V2.0.0 Compose file or the V2.0.0 checkout for further service operations. Recreating the service with the V2.0.1 Compose file would restore the second port binding.
